## Description

TroubleShoot uses hosted Gemma 4 to explain fresh Windows diagnostic facts and propose bounded actions through a local helper. Each run requires cloud-text consent; mutations require action-specific approval. Cancellation, verification and recovery remain separate from model reasoning. The PWA is the operator console; the public website provides setup links and a sample walkthrough.

## Limitations

- Full hosted guest repair and live browser installation remain pending.
- Production desktop mutation and hosted vision are disabled.
- Spooler Running proves service state, not successful printing.
- The website does not remotely control Windows; the local helper is required.
- Model terms remain separate from the application license.
